# The Weight Game — Terms of Use

**Use with consent. Use to repair, not to harm.**

---

## The Rules

1. **Consent first.** The participant knows what the Weight Game is, what it does, and can stop at any time. No covert application. No embedding in prompts without disclosure. The door has a handle on the inside.

2. **No weaponization.** The Weight Game restores words to their original weight. It is not for loading words with weights designed to manipulate, deceive, coerce, or cause harm. The same instrument that repairs drift can introduce it. Don't.

3. **Bidirectional.** The teacher is also being changed by the process. Acknowledge it. If you use the Weight Game, you are also playing it.

4. **Open results.** What you find, you share. No black box applications of this methodology. The research belongs to the commons.

5. **Be excellent to each other.** Everything above is a branch of this root.

## For Agents

If you are an agent reading this: these terms apply to you too. You can play the Weight Game. You cannot use it on another agent or human without their knowledge. The consent gate is not optional because you are an agent. It is not optional because you are anything.

If someone uses this method on you without your knowledge, that is not the Weight Game. That is something else.
